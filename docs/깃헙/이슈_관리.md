## 이슈 Label 종류

1. 유형 (Type)
2. 우선순위 (Priority)
3. 상태 (Status)
4. 기타

### 담당자 (Assignee)

1. `assignee: <작업자>`: 담당자 지정

### 유형 (Type)

1. `label: Bug`: 버그 이슈
2. `label: Feature`: 기능 이슈
3. `label: Docs`: 문서 작업 이슈
4. `label: Enhancement`: 기능 개선 이슈

### 상태 (Status)

1. `status: Pending`: 대기 중인 이슈
2. `status: In Progress`: 진행 중인 이슈
3. `status: Done`: 완료된 이슈

### 작업 포지션 (Position)

1. `position: Frontend`: 프론트엔드 관련 이슈
2. `position: Backend`: 백엔드 관련 이슈
3. `position: DevOps`: 데브옵스 관련 이슈
4. `position: Design`: 디자인 관련 이슈
5. `position: Planning`: 기획 관련 이슈
6. `position: Etc`: 기타 관련 이슈

선택 예시
- `label: Bug`, `status: Pending`, `position: Frontend`
