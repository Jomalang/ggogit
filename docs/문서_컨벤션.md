## 파일명 규칙
- 파일명은 한글로 작성한다.
- 파일 확장자는 `.md`를 사용한다.
- 파일 띄어 쓰기는 `_`로 대체한다.

## 폴더명 규칙
- 파일명은 한글로 작성한다.
- 파일 확장자는 `.md`를 사용한다.
- 파일 띄어 쓰기는 `_`로 대체한다.

## 문서 레이아웃 구성
1. 제목
2. 콜아웃 문서 메타 정보
3. 목차
4. 문서 내용

## 제목
사용 여부

`# h1 제목`
`h1`은 1번만 사용 문서의 제목으로 사용

`## h2 제목`
`h2`는 목차로 사용

`### h3 제목`
`h3`는 목차 내용의 키워드로 사용
