## Java 코드 컨벤션 정의 문서

### 코드 들여 쓰기


### 코드 if, while, for 중괄호

```java
for (초기화; 조건; 증감식) {
	반복적으로 실행할 코드;

while (조건) {
```

괄호 시작 이전에 한칸 공백

```java

```

- 중괄호 시작 이전에 한칸 공백
- `if`, `while`, `for`, `switch`,  `class`, `function` 모두 적용

### switch 문 중괄호

```java
public class SwitchExample {
    public static void main(String[] args) {
        int day = 3;
        String dayName;

        switch (day) {
            case 1: {
                dayName = "Sunday";
                break; // continue, break 중괄호 안에 선언
            } // 중괄호 사용
            case 2: {
                dayName = "Monday";
                break;
            }
            case 3: {
                dayName = "Tuesday";
                break;
            }
            case 4: {
                dayName = "Wednesday";
                break;
            }
            case 5: {
                dayName = "Thursday";
                break;
            }
            case 6: {
                dayName = "Friday";
                break;
            }
            case 7: {
                dayName = "Saturday";
                break;
            }
            default: {
                dayName = "Invalid day";
                break;
            }
        }

        System.out.println("Day: " + dayName);
    }
}

```

- switch - case : 각 case에는 중괄호 1개 (continue, break 중괄호 안으로)

### 클래스 의미있는 줄바꿈은 한칸 이상 금지

```java
public class Stack {
		// 클래스 시작시 1줄 공백
    private final char[] array;
    private int index;

    public Stack(int size) {
        this.array = new char[size];
        this.index = 0;
    }
		// 메소드별 1줄 공백
    public boolean push(char c) {
        if (empty()) { // 빈경우
            this.array[index++] = c;
            return true;
        }
				// 1줄 공백
        char top = peek();
        if ((top == '[' && ']' == c) || (top == '(' && ')' == c)) { // 닫는 경우
            pop();
            return true;
        }
				// 1줄 공백        
        this.array[index++] = c;
        return true;
    }
		// 1줄 공백
    public boolean empty() {
        return index == 0;
    }
		// 1줄 공백
    private char pop() {
        return array[--index];
    }
		// 1줄 공백
    private char peek() {
        return array[index - 1];
    }
}
```

- 의미 있는 코드별 1줄 공백

### 변수 네이밍

```java
int age;           // 좋은 예
int a;             // 나쁜 예
String customerName; // 좋은 예
String cn;          // 나쁜 예

int customerAge;        // 좋은 예
int customer_age;       // 나쁜 예 (이건 snake_case라고 합니다)
String firstName;       // 좋은 예
String first_name;      // 나쁜 예

int maxHeight;      // 좋은 예
int maxHt;          // 나쁜 예

int num1;          // 나쁜 예 의미 없는 숫자 입력 X

int numInt;          // 나쁜 예 헝가리안 표기법 X

// 복수형 네이밍
List<Customer> customers;  // 여러 Customer 객체를 저장하는 리스트
String[] names;            // 여러 이름을 저장하는 배열

List<Child> children;       // 여러 Child 객체를 저장하는 리스트 (Child의 복수형)
List<Person> people;        // 여러 Person 객체를 저장하는 리스트 (Person의 복수형)
```

- 카멜 케이스 사용
- 변수 다른사람이 이해하기 쉽게 **풀네임 지향**
- 프로그래머가 주로 사용하는 예약어 사용 가능 ( Ex: cnt, avg )
- 줄임말 사용 자제
- 배열명 끝에 (e)s 붙이기, 복수형
- 변수명에 의미없는 숫자 금지 (num1..)
- 변수명에 타입이 들어가면 안됨 (헝가리안 표기법 사용 금지)

## **Nuxt.js JavaScript 코드 컨벤션(예시)**

### 1. **코드 스타일**
- **탭/스페이스**: 스페이스 2칸을 사용합니다.
- **문장 끝**: 세미콜론(`;`)을 사용합니다.
- **문자열**: 작은 따옴표(`'`)를 사용합니다. 단, 템플릿 문자열에는 백틱(```)을 사용합니다.
- **라인 길이**: 한 줄의 최대 길이는 100자로 제한합니다.

```javascript
// Bad
let name = "Nuxt.js";

// Good
let name = 'Nuxt.js';

// Template Literal
let message = `Hello, ${name}!`;
```

---

### 2. **변수 및 상수**
- `const`와 `let`을 사용합니다. `var`는 사용하지 않습니다.
- 변수명은 **camelCase**, 상수명은 **UPPER_SNAKE_CASE**를 사용합니다.
- 불필요한 전역 변수를 선언하지 않습니다.

```javascript
// Bad
var userName = 'John';

// Good
const userName = 'John';

// Constants
const MAX_COUNT = 100;
```

---

### 3. **화살표 함수**
- 화살표 함수(`=>`)를 기본적으로 사용합니다.
- 반환값이 단일 표현식인 경우 중괄호와 `return`을 생략합니다.

```javascript
// Bad
function add(a, b) {
  return a + b;
}

// Good
const add = (a, b) => a + b;
```

---

### 4. **객체 및 배열**
- 객체와 배열 선언 시 trailing commas(마지막 쉼표)를 추가합니다.
- 구조 분해 할당(Destructuring)을 적극적으로 활용합니다.

```javascript
// Bad
const user = {
  name: 'Alice',
  age: 25
};

// Good
const user = {
  name: 'Alice',
  age: 25,
};

const { name, age } = user;
const items = [1, 2, 3,];
```

---

### 5. **ES Modules**
- 모듈 임포트/익스포트에 `import`와 `export`를 사용합니다.
- 모든 파일에 기본(`default`) 또는 명시적(`named`) 익스포트를 정의합니다.

```javascript
// Good
import Vue from 'vue';
import { mapState } from 'vuex';

// Named export
export const myFunction = () => {};

// Default export
export default {
  data() {
    return {
      message: 'Hello Nuxt.js',
    };
  },
};
```

---

### 6. **Vue 컴포넌트**
- **컴포넌트 이름**: `PascalCase`를 사용합니다.
- **템플릿**: HTML 태그는 소문자를 사용하고, 커스텀 컴포넌트는 PascalCase를 사용합니다.
- **Props**: Prop의 이름은 `camelCase`로 정의하고, 템플릿에서는 `kebab-case`로 사용합니다.

```vue
<template>
  <MyButton :button-label="labelText" />
</template>

<script>
export default {
  name: 'MyButton',
  props: {
    buttonLabel: {
      type: String,
      required: true,
    },
  },
};
</script>
```

---

### 7. **주석**
- 중요 로직이나 복잡한 코드를 설명할 때 주석을 사용합니다.
- 주석은 **단일 줄** 또는 **JSDoc** 형식으로 작성합니다.

```javascript
// Bad
// Increment by 1
counter++;

// Good
// 현재 카운터 값을 1 증가시킵니다.
counter += 1;

/**
 * 사용자 데이터를 가져옵니다.
 * @param {number} userId - 사용자 ID
 * @returns {Promise<object>} 사용자 데이터
 */
async function fetchUserData(userId) {
  // API 호출
  const response = await fetch(`/api/users/${userId}`);
  return response.json();
}
```

---

### 8. **Nuxt.js Specific**
- **페이지**: `pages` 디렉터리 안에서는 파일 이름이 URL을 정의합니다.
- **asyncData**: 비동기 데이터를 로드할 때 `asyncData` 훅을 사용합니다.
- **네임스페이스 스토어**: 모듈화를 위해 네임스페이스 스토어를 사용합니다.

```javascript
// pages/index.vue
export default {
  async asyncData({ $axios }) {
    const posts = await $axios.$get('/posts');
    return { posts };
  },
};
```
