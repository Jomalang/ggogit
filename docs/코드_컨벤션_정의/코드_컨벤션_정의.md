## Java 코드 컨벤션 정의 문서

### 코드 들여 쓰기


### 코드 if, while, for 중괄호

```java
for (초기화; 조건; 증감식) {
	반복적으로 실행할 코드;

while (조건) {
	반복적으로 실행할 코드;
```

### switch 문 중괄호

```java
public class SwitchExample {
    public static void main(String[] args) {
        int day = 3;
        String dayName;

        switch (day) {
            case 1: {
                dayName = "Sunday";
                break; // continue, break 중괄호 안에 선언
            } // 중괄호 사용
            case 2: {
                dayName = "Monday";
                break;
            }
            case 3: {
                dayName = "Tuesday";
                break;
            }
            case 4: {
                dayName = "Wednesday";
                break;
            }
            case 5: {
                dayName = "Thursday";
                break;
            }
            case 6: {
                dayName = "Friday";
                break;
            }
            case 7: {
                dayName = "Saturday";
                break;
            }
            default: {
                dayName = "Invalid day";
                break;
            }
        }

        System.out.println("Day: " + dayName);
    }
}

```

- switch - case : 각 case에는 중괄호 1개 (continue, break 중괄호 안으로)

### 클래스 의미있는 줄바꿈은 한칸 이상 금지

```java
public class Stack {
		// 클래스 시작시 1줄 공백
    private final char[] array;
    private int index;

    public Stack(int size) {
        this.array = new char[size];
        this.index = 0;
    }
		// 메소드별 1줄 공백
    public boolean push(char c) {
        if (empty()) { // 빈경우
            this.array[index++] = c;
            return true;
        }
				// 1줄 공백
        char top = peek();
        if ((top == '[' && ']' == c) || (top == '(' && ')' == c)) { // 닫는 경우
            pop();
            return true;
        }
				// 1줄 공백        
        this.array[index++] = c;
        return true;
    }
		// 1줄 공백
    public boolean empty() {
        return index == 0;
    }
		// 1줄 공백
    private char pop() {
        return array[--index];
    }
		// 1줄 공백
    private char peek() {
        return array[index - 1];
    }
}
```

- 의미 있는 코드별 1줄 공백

### 변수 네이밍

```java
int age;           // 좋은 예
int a;             // 나쁜 예
String customerName; // 좋은 예
String cn;          // 나쁜 예

int customerAge;        // 좋은 예
int customer_age;       // 나쁜 예 (이건 snake_case라고 합니다)
String firstName;       // 좋은 예
String first_name;      // 나쁜 예

int maxHeight;      // 좋은 예
int maxHt;          // 나쁜 예

int num1;          // 나쁜 예 의미 없는 숫자 입력 X

int numInt;          // 나쁜 예 헝가리안 표기법 X

// 복수형 네이밍
List<Customer> customers;  // 여러 Customer 객체를 저장하는 리스트
String[] names;            // 여러 이름을 저장하는 배열
int[] ages;                // 여러 나이를 저장하는 배열

List<Child> children;       // 여러 Child 객체를 저장하는 리스트 (Child의 복수형)
List<Person> people;        // 여러 Person 객체를 저장하는 리스트 (Person의 복수형)
```

- 카멜(camelCase : 낙타) 케이스 사용
- 변수 다른사람이 이해하기 쉽게 **풀네임 지향**
- 프로그래머가 주로 사용하는 예약어 사용 가능 ( Ex: cnt, avg )
- 줄임말 사용 자제
- 배열명 끝에 (e)s 붙이기, 복수형
- 변수명에 의미없는 숫자 금지 (num1..)
- 변수명에 타입이 들어가면 안됨 (헝가리안 표기법 사용 금지)

### 참조 변수 네이밍

```java
private Customer customer;         // 단일 Customer 객체를 참조
private Order currentOrder;        // 단일 Order 객체를 참조
private PaymentProcessor paymentProcessor; // 단일 PaymentProcessor 객체를 참조
```

- 자주 사용하는 API나 플랫폼 객체는 줄여쓰기 가능 객체는 줄이되 대문자들을
  약자로 ex: `FileInputStream fis = new FileInputStream();`
- 개발자가 직접 만든 객체는 풀네임 지향

### 객체 네이밍

```java
public class CustomerManager {
    // 클래스 이름은 PascalCase를 따릅니다.
}

public class Product {
    // 명확하고 의미 있는 이름을 사용합니다.

```

- **파스칼 케이스 (PascalCase) 사용**: 클래스 이름의 첫 글자와 각 단어의 첫 글자를 대문자로 씁니다.
- **명확하고 의미 있는 이름 사용**: 클래스가 무엇을 나타내는지 명확하게 설명합니다.
